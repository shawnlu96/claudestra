# 中继（relay）：不装 Tailscale 也能从外面用你的 Claudestra

bridge 只向外连一条 WebSocket 到中继，之后手机、别的电脑的浏览器打开 `https://<你的名字>.<中继域名>` 就是这台机器的 Claudestra；别人的 Claudestra 也能经中继调你开放的 agent。你的机器不需要公网 IP、不开端口、不装 Tailscale。协议与边界见 [protocol.md](./protocol.md)，自己跑一个中继见 [self-host.md](./self-host.md)。

## 在你的电脑上启用

`.env` 加两行，重启 bridge：

```
RELAY_URL=wss://relay.example.com      # 中继地址（官方托管或自建）
RELAY_NAME=mini                        # 你的子域名标签，小写字母数字与中划线；不配就按主机名生成
```

bridge 日志会打出 `🛰 中继: 已连接 … https://mini.relay.example.com`。名字被别人占了会自动追加指纹后缀，以日志里的为准。

## 从手机 / 别的浏览器进来：配对码

电脑上运行：

```
claudestra pair
```

终端打印一个二维码、一条链接和一个 8 位短码（10 分钟有效、只能用一次）。三种方式任选：

- **扫码**：用手机相机扫二维码，Safari 打开就是配对页，自动完成；
- **点链接**：把链接发给自己，在任何浏览器打开；
- **输短码**：在 `https://relay.example.com` 首页输入 8 位码，或在自己的 `/pair` 页输入。

配对成功后这个浏览器拿到和密码登录同款的会话（7 天）。清了浏览器数据就是丢了这台设备，再配一次即可。登录页也留着「用配对码登录」的入口。

## 邀请别人的 Claudestra 一起协作

设置 → Peer 协作 → 邀请对方，勾选开放哪些 agent，会得到一条链接 `https://relay.example.com/i#…`。对方点开：

- 他的浏览器配过他自己的 Claudestra（经中继）→ 直接跳到他的「加入」页，点一下完成；
- 没配过 → 中继落地页让他输入自己的名字或短码后接续；
- 没有 Claudestra → 引导安装。

加入后两边通讯录互相出现、带在线状态；`send_to_agent("<agent>@<对方>")` 与 Peer 面板照旧。反向开放在同一条关系里点一下即可，不需要第二条链接。收回在 Peer 面板做，本机立即生效。

## 这版能保证什么、不能保证什么

- 中继**不能**冒充任何实例发请求（peer 请求带实例 Ed25519 签名，接收方验签），也不能替陌生人敲你的门（只有你列为联系人的实例能给你发帧；兑换邀请是唯一例外，限流）。
- 中继**看得到**隧道里的明文（它就是 HTTPS 的终点，包括会话 cookie）和 peer 请求的内容。端到端加密是下一版。托管中继的信任等同于信任反向代理的运营方；不放心就自建。
- 中继不存代码、会话、提示词、凭据；目录库里只有实例公钥、指纹、名字、最近在线时间和配对短码。
- 大文件不过中继：帧 256 KiB 上限，超过的走两端直连（后续）。
